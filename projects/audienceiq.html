Why it's different

Personas backed by math, then written up by AI

Most "AI persona" tools skip straight to the LLM and ask it to imagine a customer base. AudienceIQ clusters your actual data first — the writing is downstream of the math, not a substitute for it.

Unified data integration

Four separate report types — demographics, repeat-purchase behavior, market-basket pairings, search terms — get merged into one feature set automatically, cutting research time from hours to minutes.

Real clustering, not vibes

Weighted k-means (k-means++ seeding, deterministic, multiple restarts) runs server-side over your demographic distributions before any language model sees the data.

End-to-end, actionable output

Every persona connects straight to a listing fix and a set of creative prompts — insight and action ship together, not as separate deliverables.

The workflow

Three steps, one upload

The whole flow is designed to run per-product in one sitting — no data science background required on the way in.

STEP 01

Upload your reports

Drop in demographics (required) plus repeat-purchase, market-basket, and top-search-term CSVs. Column names are matched flexibly, so exports from most analytics platforms work as-is.

STEP 02

Real ML clustering runs

Demographic breakdowns are turned into weighted feature cells and clustered with k-means — the same segments a data analyst would find doing this by hand, just automated.

STEP 03

Apply the personas

Claude turns each cluster into a full persona, then generates listing enhancement suggestions and creative image prompts tied directly back to that segment's pain points.

Inputs

Four reports, one feature set

Each report answers a different question about the customer base — together they give the clustering step enough signal to find real segments.

Required

Demographics

Who buys: age, income, gender breakdowns as % of sales — the primary input to clustering.

Optional

Repeat purchase behavior

Repeat vs. one-time customer split, average orders, days between purchases.

Optional

Market basket analysis

Which products get bought together — feeds cross-sell logic into listing suggestions.

Optional

Top search terms

The exact keywords customers use to find the product — grounds the listing rewrite in real search intent.

Before you run it

Tips for better output

1

Complete beats perfect. Upload all four reports when you have them — segment quality depends on how much signal the clustering step gets.

2

Review before you ship. Personas are a strong first draft grounded in real numbers, not a final answer — read them before handing them to a team.

3

Re-run per product. Segments are specific to one product's data; run the flow again for each ASIN or SKU you want personas for.

4

Prioritize by reliability score. Higher scores represent a larger, more confident share of the customer base — start there.
